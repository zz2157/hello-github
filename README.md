# hello-github

我的第一个 GitHub 仓库，用来练习完整工作流。

## 这个仓库演示了什么

1. 本地初始化仓库（`git init`）
2. 暂存与提交（`git add` / `git commit`）
3. 关联远程仓库（`git remote add`）
4. 推送到 GitHub（`git push`）

## 目录

| 文件 | 作用 |
|---|---|
| `README.md` | 仓库说明，显示在 GitHub 首页 |
| `.gitignore` | 告诉 Git 哪些文件不要提交 |
| `hello.py` | 一个最小可运行脚本 |
| `notes.md` | 学习笔记 |

## 运行

```bash
python hello.py
```

## 常用命令速查

```bash
git status            # 看改了什么
git add .             # 全部暂存
git commit -m "msg"   # 提交
git push              # 推到 GitHub
```
